# Sneh Patel — Portfolio (Astro + Tailwind)

This repo contains an Astro + Tailwind starter for a personal portfolio.

Local development
1. Install dependencies
   npm install

2. Start dev server
   npm run dev
   Open http://localhost:3000 or use Codespaces forwarded URL.

Build
- npm run build
- npm run preview

Deploy
- Connect the repo to Vercel for preview and production deployments. Use build command: `npm run build`.
